# Enterprise IT Support Lab — Project Charter

## Project Overview

The Enterprise IT Support Lab is a hands-on portfolio project designed to simulate a small enterprise IT environment.

The lab demonstrates practical experience in:

* Linux system administration
* SQL database administration
* Application and production support
* Incident management
* Root cause analysis
* Monitoring and log analysis
* Bash automation
* Technical documentation
* Cybersecurity integration

The project is designed to reflect common responsibilities performed by Application Support Engineers, Production Support Engineers, System Administrators, Database Administrators, and Security Operations professionals.

---

## Business Scenario

MissionIT Solutions Ltd. is a fictional software and IT services company based in Sweden.

The company has approximately 200 employees who use an internal business application for:

* Employee authentication
* Customer management
* Support ticket management
* Application status monitoring
* Operational reporting

The IT Support team is responsible for maintaining application availability, resolving incidents, supporting users, monitoring systems, managing databases, and documenting technical solutions.

This lab simulates the work performed by the IT Support team.

---

## Project Objectives

The main objectives of this project are to:

1. Build a realistic enterprise-style IT environment.
2. Practice Linux server administration.
3. Practice SQL database administration.
4. Troubleshoot application and infrastructure incidents.
5. Analyze logs and identify root causes.
6. Create Bash scripts for common operational tasks.
7. Develop incident reports, runbooks, SOPs, and knowledge-base articles.
8. Practice monitoring and service health checks.
9. Build an interview-ready technical portfolio.
10. Extend the environment into cybersecurity and security monitoring.

## Success Criteria

The project will be considered successful when:

* The lab environment is fully documented.
* The Linux server and Windows workstation can communicate.
* The application can connect to the database.
* Common support incidents can be reproduced and resolved.
* Monitoring and automation scripts work successfully.
* Incident reports and RCA documents are completed.
* The project can be confidently explained during an interview.
* The repository demonstrates practical and honest technical experience.
