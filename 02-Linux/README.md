# Linux Administration Labs

## Overview

This section contains hands-on Linux administration labs completed as part of the **Enterprise IT Support Lab**.

The labs simulate common IT Support and System Administration tasks in an Ubuntu Server environment, including user administration, group management, file permissions, access control, troubleshooting, and verification.

The objective is to demonstrate practical Linux skills through documented technical tasks and supporting evidence.

---

## Completed Labs

### 03 - Linux User Management

Hands-on user administration including user creation, password assignment, account verification, and validation of the user's home directory.

**Skills:** Linux User Administration, `useradd`, `passwd`, `id`, Account Verification

[View Linux User Management Lab](./03-Linux-User-Management/)

---

### 04 - Linux Group Management

Linux group administration including group creation, adding and removing users from groups, membership verification, and group cleanup.

**Skills:** Linux Group Administration, `groupadd`, `usermod`, `gpasswd`, `getent`, Access Management

[View Linux Group Management Lab](./04-Linux-Group-Management/)

---

### 05 - Linux File Permissions

Linux file permission and ownership management using `chmod` and `chown`.

The lab includes permission modification, ownership changes, user-context access testing, permission-denied validation, troubleshooting, and cleanup.

**Skills:** Linux Permissions, `chmod`, `chown`, File Ownership, Access Control, Troubleshooting

[View Linux File Permissions Lab](./05-Linux-File-Permissions/)

---

### 06 - Linux Service Management & Troubleshooting

Linux service management and troubleshooting focused on SSH availability, systemd socket activation, controlled outage simulation, service recovery, log analysis, and remote-access verification.

The lab also includes troubleshooting a VirtualBox host-to-VM connectivity issue and configuring a dedicated Host-Only management network using Netplan.

**Skills:** Linux Troubleshooting, `systemctl`, `journalctl`, `ss`, SSH, systemd Socket Activation, Netplan, VirtualBox Networking

[View Linux Service Management & Troubleshooting Lab](./06-Linux-Troubleshooting/)
